# 19. Troubleshooting Git & GitHub Issues

This diagnostic guide provides solutions for common Git and GitHub issues across Windows PowerShell, Git Bash, and macOS/Linux.

---

## 1. Authentication and Permission Denied (`publickey`)

### Error:
```text
git@github.com: Permission denied (publickey).
fatal: Could not read from remote repository.
```

### Resolution Steps:

#### 1. Verify and Start SSH Agent:

**Windows PowerShell (Run as Administrator):**
```powershell
Get-Service ssh-agent | Set-Service -StartupType Automatic
Start-Service ssh-agent
ssh-add $HOME\.ssh\id_ed25519
```

**macOS / Linux / Git Bash:**
```bash
eval "$(ssh-agent -s)"
ssh-add ~/.ssh/id_ed25519
```

#### 2. Confirm GitHub Key Registration:
Copy the public key:
- **Windows PowerShell:** `Get-Content $HOME\.ssh\id_ed25519.pub | Set-Clipboard`
- **macOS:** `pbcopy < ~/.ssh/id_ed25519.pub`
- **Linux:** `cat ~/.ssh/id_ed25519.pub`

Add to **GitHub** -> **Settings** -> **SSH and GPG keys**, then test:
```bash
ssh -T git@github.com
```

## 2. HTTPS Credential Reset

When your personal access token or password changes, cached credentials must be refreshed.

### Inspect Configured Helper:
```bash
git config --show-origin --get-all credential.helper
```

### Clear Saved Credentials:
- **Windows:** Search for **Credential Manager** -> **Windows Credentials** -> Remove `git:https://github.com`.
- **macOS:** Open **Keychain Access** -> Search for `github.com` -> Delete entry.
- **Command Line Reset (`git credential reject`):**
  - **Linux / macOS / Git Bash:**
    ```bash
    printf "protocol=https\nhost=github.com\n\n" | git credential reject
    ```
  - **Windows PowerShell:**
    ```powershell
    @"
    protocol=https
    host=github.com

    "@ | git credential reject
    ```

## 3. Resolving Detached HEAD State

`HEAD` is detached when you check out a commit hash or remote tag directly instead of a local branch.

```bash
git status
# Output: HEAD detached at 5a0e23d
```

### To Keep Commits Made While Detached:
```bash
git switch -c recovery-branch
```

### To Discard and Return to Normal:
```bash
git switch main
```

## 4. Line Ending Issues (CRLF vs LF)

Windows uses Carriage Return + Line Feed (`CRLF`), whereas Linux and macOS use Line Feed (`LF`).

### Configuration:
- **Windows:**
  ```powershell
  git config --global core.autocrlf true
  ```
- **macOS / Linux:**
  ```bash
  git config --global core.autocrlf input
  ```

## 5. Updates Rejected (Fetch First)

```text
! [rejected] main -> main (fetch first)
error: failed to push some refs to 'https://github.com/...'
```

### Solution:
Do not force push. Pull the remote changes, rebase your local work on top, and push:
```bash
git pull --rebase origin main
git push origin main
```

## Diagnostic Matrix

| Error Message | Cause | Resolution |
|---|---|---|
| `fatal: not a git repository` | Command executed outside a Git directory | Navigate to repository root or run `git init` |
| `error: src refspec main does not match any` | Branch has zero commits | Create an initial commit: `git commit -m "initial"` |
| `fatal: refusing to merge unrelated histories` | Merging two distinct projects | `git pull origin main --allow-unrelated-histories` |
| `error: Your local changes would be overwritten` | Uncommitted work conflicts with incoming changes | Stash changes: `git stash -u`, run `git pull`, then `git stash pop` |
