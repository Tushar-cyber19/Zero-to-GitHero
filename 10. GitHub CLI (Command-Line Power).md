# 10. GitHub CLI (Command-Line Power)

The **GitHub CLI (`gh`)** brings the complete functionality of GitHub directly to your terminal, allowing developers to manage repositories, review Pull Requests, trigger CI/CD pipelines, publish releases, and configure secrets without opening a web browser.

---

## 1. Installation & Authentication

### Installation

- **Windows (winget):**
  ```powershell
  winget install --id GitHub.cli
  ```
- **Windows (scoop):**
  ```powershell
  scoop install gh
  ```
- **macOS (Homebrew):**
  ```bash
  brew install gh
  ```
- **Linux (Debian / Ubuntu):**
  ```bash
  type -p curl >/dev/null || sudo apt install curl -y
  curl -fsSL https://cli.github.com/packages/githubcli-archive-keyring.gpg | sudo dd of=/usr/share/keyrings/githubcli-archive-keyring.gpg
  echo "deb [arch=$(dpkg --print-architecture) signed-by=/usr/share/keyrings/githubcli-archive-keyring.gpg] https://cli.github.com/packages stable main" | sudo tee /etc/apt/sources.list.d/github-cli.list > /dev/null
  sudo apt update && sudo apt install gh -y
  ```

### Authentication
```bash
gh auth login
```
Follow the interactive prompts:
1. Select **GitHub.com**
2. Choose protocol (**HTTPS** or **SSH**)
3. Authenticate with a web browser (or Personal Access Token).

Verify authentication:
```bash
gh auth status
```

## 2. Repository Operations

### Create a repository and push local code:
```bash
gh repo create my-project --public --source=. --remote=origin --push
```

### Clone a repository:
```bash
gh repo clone owner/repository
```

### Fork a repository and clone locally:
```bash
gh repo fork owner/repository --clone
```

### Synchronize a fork with upstream:
Keep your fork completely updated with the upstream repository without typing manual fetch and merge commands:
```bash
gh repo sync
```

---

## 3. Pull Request Workflows

### Create a Pull Request:
```bash
# Interactive prompt
gh pr create

# Non-interactive with automated commit notes
gh pr create --title "feat: add user authentication" --body "Closes #42" --base main
```

### Checkout a Pull Request locally to test:
```bash
gh pr checkout 128
```
This fetches the branch for PR #128 and checks it out locally.

### View PR diff and checks:
```bash
gh pr diff
gh pr checks
```

### Approve and Merge a PR:
```bash
# Approve with comment
gh pr review --approve -b "LGTM, verified locally."

# Squash, merge, and delete remote branch
gh pr merge --squash --delete-branch
```

---

## 4. Managing GitHub Releases

### Create a versioned release with automated release notes:
```bash
gh release create v1.2.0 --title "v1.2.0: Core Architecture Upgrade" --generate-notes
```

### Attach compiled binary assets or zip archives:
```bash
gh release create v1.2.0 ./dist/bundle.zip --generate-notes
```

### List releases:
```bash
gh release list
```

---

## 5. Monitoring GitHub Actions CI/CD

### List recent workflow runs:
```bash
gh run list
```

### View failed run logs directly in terminal:
```bash
gh run view <run-id> --log-failed
```

### Re-run failed jobs:
```bash
gh run rerun <run-id> --failed
```

---

## 6. Repository Governance & Secrets

### List repository rulesets:
```bash
gh ruleset list
```

### Manage repository secrets:
```bash
# List configured secrets
gh secret list

# Set an encrypted secret
gh secret set API_KEY
```

## Command Reference

| Command | Action |
|---|---|
| `gh auth status` | Verify authentication status |
| `gh repo sync` | Synchronize fork with upstream |
| `gh pr create` | Create a new Pull Request |
| `gh pr checkout <id>` | Checkout a PR locally |
| `gh pr merge --squash` | Squash-merge PR and delete branch |
| `gh release create <tag> --generate-notes` | Create release with automated notes |
| `gh run list` | View recent CI/CD workflow runs |
| `gh run view <id> --log-failed` | Stream failed CI logs in terminal |
| `gh secret set <name>` | Configure an encrypted secret |
| `gh browse` | Open current repository in browser |
