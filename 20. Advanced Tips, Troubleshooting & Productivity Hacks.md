# 20. Advanced Tips, Troubleshooting & Productivity Hacks

This guide compiles command aliases, productivity configurations, and advanced Git optimizations for daily development efficiency.

---

## 1. Productivity Aliases

Configuring command aliases reduces repetitive typing and speeds up daily workflows.

```bash
# Compact status
git config --global alias.st "status -sb"

# Graphical history tree
git config --global alias.lg "log --oneline --graph --decorate --all"

# Concise commit
git config --global alias.cm "commit -m"

# Modern branch switch
git config --global alias.sw "switch"
git config --global alias.sc "switch -c"

# Unstage files
git config --global alias.unstage "restore --staged"
```

---

## 2. Git Autocorrect

Enable Git to automatically execute mistyped commands after a brief confirmation delay:

```bash
# Enables autocorrect with a 2-second countdown
git config --global help.autocorrect 20
```

---

## 3. Global `.gitignore` Configuration

Configure a system-wide `.gitignore` for operating system artifacts (such as `.DS_Store` or `Thumbs.db`):

```bash
# 1. Create global ignore file
git config --global core.excludesfile ~/.gitignore_global

# 2. Add common system entries
echo ".DS_Store" >> ~/.gitignore_global
echo "Thumbs.db" >> ~/.gitignore_global
echo "*.log" >> ~/.gitignore_global
```

---

## 4. Reusing Recorded Conflict Resolutions (`git rerere`)

When rebasing long-lived branches, resolving the same merge conflicts repeatedly can be tedious. Enabling `rerere` (Reuse Recorded Resolution) instructs Git to remember how you resolved a conflict and automatically apply that same resolution in the future:

```bash
git config --global rerere.enabled true
```
