# 02. Setting Up Git and GitHub

This guide covers downloading, installing, and configuring Git on Windows, macOS, and Linux, along with setting up your user identity and SSH key authentication with GitHub.

---

## 1. Installing Git

### Windows
1. Download the installer from the official website: [git-scm.com/downloads](https://git-scm.com/downloads).
2. Run the installer. Recommended default options:
   - Default editor: Visual Studio Code (or your preferred editor).
   - Default branch name for new repositories: `main`.
   - Adjusting PATH environment: Git from the command line and also from 3rd-party software.
   - Line ending conversions: Checkout Windows-style, commit Unix-style line endings (`core.autocrlf true`).

Alternatively, install via Windows Package Manager (`winget`):
```powershell
winget install --id Git.Git -e --source winget
```

### macOS
Install via Homebrew:
```bash
brew install git
```
Or install Apple's Command Line Developer Tools:
```bash
xcode-select --install
```

### Linux
Debian / Ubuntu:
```bash
sudo apt update
sudo apt install git -y
```

Fedora / RHEL:
```bash
sudo dnf install git -y
```

---

## 2. Verifying Installation

Open your terminal (PowerShell, Command Prompt, or terminal) and verify that Git is on your system PATH:

```bash
git --version
```

Expected output:
```text
git version 2.45.0
```

## 3. Configuring User Identity

Git attaches your name and email address to every commit you create. Set these globally so all future repositories inherit them:

```bash
git config --global user.name "Your Name"
git config --global user.email "your-email@example.com"
git config --global init.defaultBranch main
```

### Line Ending Configuration
To prevent cross-platform whitespace issues:
- **Windows:**
  ```powershell
  git config --global core.autocrlf true
  ```
- **macOS / Linux:**
  ```bash
  git config --global core.autocrlf input
  ```

### Inspect Configuration:
```bash
git config --list --show-origin
```

## 4. Setting Up SSH Authentication

SSH keys provide encrypted, passwordless authentication between your computer and GitHub.

### Step 1: Generate an SSH Key Pair
Generate a modern Ed25519 key:

```bash
ssh-keygen -t ed25519 -C "your-email@example.com"
```
Press `Enter` to accept the default file location, then optionally enter a passphrase.

### Step 2: Start the SSH Agent and Add Key

**On Windows (PowerShell - Run as Administrator if needed):**
```powershell
Get-Service ssh-agent | Set-Service -StartupType Automatic
Start-Service ssh-agent
ssh-add $HOME\.ssh\id_ed25519
```

**On macOS:**
```bash
eval "$(ssh-agent -s)"
ssh-add --apple-use-keychain ~/.ssh/id_ed25519
```

**On Linux (or Git Bash):**
```bash
eval "$(ssh-agent -s)"
ssh-add ~/.ssh/id_ed25519
```

### Step 3: Copy Your Public Key

**Windows PowerShell:**
```powershell
Get-Content $HOME\.ssh\id_ed25519.pub | Set-Clipboard
```

**macOS:**
```bash
pbcopy < ~/.ssh/id_ed25519.pub
```

**Linux:**
```bash
cat ~/.ssh/id_ed25519.pub
```

### Step 4: Add Public Key to GitHub
1. Log in to [github.com](https://github.com/) and navigate to **Settings** -> **SSH and GPG keys**.
2. Click **New SSH key**.
3. Give it a descriptive Title (e.g., "Work Laptop") and paste the public key into the Key box.
4. Click **Add SSH key**.

### Step 5: Test Connection
```bash
ssh -T git@github.com
```
Expected output:
```text
Hi username! You've successfully authenticated, but GitHub does not provide shell access.
```

## 5. Setting Up Your Default Editor (Optional)

Configure your preferred text editor for writing commit messages:

```bash
# Visual Studio Code
git config --global core.editor "code --wait"

# Nano
git config --global core.editor "nano"

# Vim
git config --global core.editor "vim"
```
